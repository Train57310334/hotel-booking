# ยินดีต้อนรับสู่ BookingKub

คู่มือนี้จะช่วยให้คุณตั้งค่าโรงแรมและพร้อมรับการจองแรกใน 5 ขั้นตอนง่ายๆ

### 1. ตั้งค่าข้อมูลโรงแรม
ไปที่ **Settings (การตั้งค่า)** เพื่อกรอกชื่อโรงแรม ที่อยู่ และอัปโหลดโลโก้ของคุณ

### 2. สร้างประเภทห้องพัก
ไปที่ **Rooms > Room Types** เพื่อสร้างประเภทห้องพักหลัก เช่น Deluxe, Standard

### 3. เพิ่มห้องพักจริง
ใน **Rooms** ให้เพิ่มหมายเลขห้องพักจริงๆ ที่เชื่อมกับประเภทห้องพักที่สร้างไว้

### 4. ตั้งค่าแพ็กเกจราคา
กำหนดราคาใน **Rates** คุณสามารถสร้างราคามาตรฐาน ราคาไม่คืนเงิน หรือราคาตามฤดูกาลได้

### 5. ตั้งค่าระบบชำระเงิน
ใน **Settings** ให้กรอก Payment Gateway Keys (Stripe หรือ Omise) เพื่อรับการจองออนไลน์
